Roadmap (Item 34-41)

Phase 0 — Audit: inventário, arquitetura, segurança, debt.
Phase 1 — Foundation: backend, DB, auth, videos, feed, analytics.
Phase 2 — Creator Platform: dashboard, monetização, live.
Phase 3 — Decentralized Infra: P2P, DHT, storage, relay, replicação.
Phase 4 — Blockchain Testnet: genesis, nós, consenso, wallet, NST.
Phase 5 — Security: threat model, auditoria, pentest, DR.
Phase 6 — Mainnet: só após auditoria independente + testes de consenso + DR validado.
Phase 7 — Global Scale: expansão geográfica, DAO, enterprise.
