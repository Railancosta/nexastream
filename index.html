O que e

Plataforma de video, rede e economia em uma so camada

Video, entrega P2P, armazenamento distribuido e token nativo desenhados para funcionar juntos, com seguranca primeiro.

VIDEO

Plataforma de video

Upload resumivel por chunks, content-addressing SHA-256 e API REST versionada. O hash e calculado no servidor - nunca confiamos no hash enviado pelo cliente.

P2P

Rede P2P (WebRTC)

Servidor de sinalizacao coordenando SDP/ICE e membership de salas. O signaling nunca transporta o video - apenas coordena os pares. Fallback HTTP garantido.

STORE

Armazenamento distribuido

Interface ContentStorage (put/get/has/delete) com enderecamento por hash. Primeira implementacao local; adapters S3/IPFS nos proximos modulos.

CHAIN

Blockchain nativa NST

Token NST com supply maximo de 55.000.000 como invariavel. Contratos de recompensas, tesouro e staking - ainda em prototipo, nao auditados.

ECON

Economia 50/50

50% da receita distribuida elegivel vai para criadores, 50% para a plataforma. Ledger auditavel, operacoes idempotentes, sem ponto flutuante para valores.

SEC

Seguranca primeiro

Inputs validados com Zod, CORS estrito, rate limiting, sem segredos no repositorio. O browser e nao-confiavel; o cliente nunca e autoridade.

Arquitetura

Camadas que nao dependem dos detalhes internas umas das outras

Do cliente ao blockchain, cada camada tem uma responsabilidade clara.

CLIENTSWeb / Mobile - player hibrido (CDN primeiro, P2P depois), upload, perfis de criador
SERVICESAPI REST v1 (auth, upload, video, busca) - Node.js + TypeScript + Zod
NETWORKSignaling WebRTC, DHT, relay, nos P2P - NAT traversal via STUN/TURN
STORAGECamada distribuida compativel com IPFS - enderecamento por conteudo SHA-256
BLOCKCHAINNexaChain / NST - ledger, governanca, staking

Regras do token

  • Supply maximo como invariavel - nenhum mecanismo pode ultrapassa-lo.
  • Sem mint infinito, sem funcoes administrativas escondidas.
  • Acesso por controle explicito de roles (USER, CREATOR, MODERATOR...).
  • Recompensas deterministicas, auditaveis e com anti-fraude.
